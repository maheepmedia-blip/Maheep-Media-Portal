# Admin Guide — Maheep News Portal

## Accessing the Dashboard
Visit `/admin` and sign in with `maheepmedia@gmail.com` (or your claimed admin credentials).

## Key Workflows
- **Articles**: Create, edit, upload images, toggle `Featured` / `Breaking`, run bulk Publish/Draft/Delete, or invoke the **AI News Assistant** (Summarize, Suggest Headlines, Auto-Categorize, Translate EN/HI, Draft Intro, Quality Check).
- **RSS Engine**: Add RSS 2.0 or Atom feeds, test connectivity live, enable/disable individual sources, run all feeds on demand, or retry individual failed feeds.
- **Publishing & AI Mode**: Switch between `Manual Editorial Approval`, `Automatic Publishing`, and `Automatic Publishing with AI Quality Checks`, and set the background collection interval (`15m`–`180m`).
- **E-Paper Generator**: Generate today's or any historical date's multi-page A4 broadsheet, preview HTML print view, or download a multi-page A4 PDF.
- **Contacts & Newsletter**: Review reader inquiries, update status (`new` -> `reviewed` -> `resolved`), and export newsletter subscribers to CSV.
