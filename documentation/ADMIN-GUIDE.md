# Admin Guide — Maheep Media / Maheep News Portal

## Accessing the Dashboard
Visit `/admin` and sign in with `maheepmedia@gmail.com` (or your authorized editorial role account).

## Key Workflows
- **Articles, Scheduling & Revisions**: Create/edit bilingual articles, upload persistent images, set `Asia/Kolkata` (`IST`) `scheduled_at` and `unpublish_at` timestamps, preview drafts via secure preview links, compare/restore saved `Revisions`, toggle `Featured` / `Breaking`, run bulk actions, or invoke the **AI News Assistant** (Summarize, Headlines, Categorize, Translate EN/HI, Draft Intro, Advisory Quality & Neutrality Audit).
- **Editorial Calendar**: Visual monthly planning calendar highlighting scheduled, pending, and published articles and daily E-Paper editions.
- **RSS Automation Engine**: Manage RSS 2.0 / Atom feeds, test feeds live, collect on demand, inspect import logs, and retry failed feeds with automatic breaking-news candidate detection.
- **E-Paper Generator & Ads**: Generate printable A4 broadsheets for any date with multi-page PDF download, and manage sponsor/ad slots across homepage and article placements.
- **Community & Engagement**: Moderate reader comments (`pending` / `approved` / `rejected`), manage double opt-in newsletter subscribers, review reader inquiries, and broadcast Web Push breaking alerts.
- **System Ops & Backups (Super Admin)**: Inspect `/api/health` storage integrity, run/monitor scheduled cron jobs, retry failed emails, inspect admin audit & AI usage logs, and create, download, or restore verified SQLite database backups.
